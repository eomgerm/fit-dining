# 원칙 던전 — 최소 실행 프로토타입

자연어 원칙 → Rule JSON → 시드 기반 던전 → 불변 이벤트 로그 → 결과와 리플레이가 한 페이지에서 동작합니다. 별도 서버나 계정은 필요 없습니다.

## 실행

`principle-dungeon` 폴더에서 정적 서버를 실행하고 브라우저로 접속하세요. 예: Python 3이 있으면 `python -m http.server 8000` 후 <http://localhost:8000>을 엽니다. ES 모듈을 사용하므로 파일을 직접 더블 클릭하는 방식은 브라우저에 따라 제한될 수 있습니다.

## 사용

샘플 원칙 3종 중 하나를 선택하거나 200자 이내로 작성합니다. 시드와 수정자를 고른 후 **원칙 해석하고 던전 실행**을 누릅니다. 오른쪽에서 결과, 방 경로, 각 조우의 발동 규칙과 상태 변화를 확인할 수 있습니다. 이벤트 로그 전체는 JSON으로 저장할 수 있습니다.

## 구현 범위

- 파서는 제한된 한국어 표현을 해석합니다. 미지원 문장은 화면에 표시하며, 해당 상황에서는 기본 행동을 사용합니다. AI/LLM은 연결하지 않았습니다.
- 방은 몬스터, 함정, 상인, 보물, 보스 5종이며 행동은 공격, 방어, 회피, 해제, 구매, 무시, 열기, 후퇴, 물약 사용입니다.
- 수정자는 기본 던전, 함정 2배, 상인 불신 금지 3종입니다.
- 던전 생성과 판정은 `engine.mjs`의 정수 PRNG만 사용합니다. **같은 시드 + 같은 파싱 규칙 + 같은 수정자**는 같은 이벤트와 결과를 냅니다.
- 로그 객체는 생성 후 깊게 동결합니다. 내려받은 JSON은 실행 당시의 결과 스냅샷입니다. 브라우저 밖의 영구 저장소는 없습니다.

## 검증

Node.js 18 이상에서 `node --test engine.test.mjs`를 실행하세요.

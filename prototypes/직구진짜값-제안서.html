직구 진짜값

알리·테무·아마존 상품 페이지를 열면 가격 옆에 원화 최종 예상가가 뜬다. 배송비, 관부가세, 카드 수수료, 환율까지 더한 값이다. 그 아래에 "90일 중 어느 가격인지"와 "테무·쿠팡·네이버에선 얼마인지"가 나란히 선다. 사용자는 아무것도 입력하지 않는다.

읽는 데 7분. 재미 축 "원칙 던전"과 짝을 이루는 유익 축 제안이다. 제안자의 실제 고충(이게 진짜 싼지, 최종가인지, 다른 데가 더 싼지)에서 출발했다. 숫자에는 출처를 달았고 확인 못 한 것은 미확인으로 표시했다. 데모의 가격·세율·환율은 예시다.

1. 세 질문이 곧 세 기능

"이게 최종가 맞아?"상품가 + 배송비 + 관부가세 + 카드 수수료 + 환율을 항목별로 보여 준다. 면세 한도(150달러, 미국발 200달러)까지 남은 금액과 원화 결제(DCC) 함정 경고를 같이 띄운다[1][2].
"진짜 싼 거야?"같은 상품을 본 사용자들의 열람 가격이 익명으로 쌓여 "90일 중 하위 20%" 같은 위치가 뜬다. 알리의 '할인 전 가격'이 아니라 실제 관측값 기준이다.
"다른 데가 더 싸지 않아?"알리·테무·아마존(직구끼리)과 쿠팡·네이버 최저가(국내)를 최종가 기준으로 나란히. 알리가 쿠팡보다 비싼 품목이 보도될 만큼 "직구가 항상 싸진 않다"[3].

면접 한 줄: 데이터 품질과 세법 변경을 감시하는 운영 층을 만들어 "틀린 최종가"가 사용자에게 나가기 전에 막았다.

A(리더)가 모든 슬라이스의 입력이라 병목이 될 수 있다. 1주차에 알리 어댑터 하나와 관측 JSON 계약을 먼저 넘기고, 나머지 사이트는 A가 순차로 늘린다. B는 규칙만으로 먼저 출시하고 분류기는 교정 라벨이 쌓인 뒤 붙인다.

6. 이 주제의 이점

  • 제안자의 진짜 고충이다. 첫 사용자가 우리이고, 쓸 때마다 돈이 보여서 피드백이 빠르다.
  • 습관 위에 얹힌다. 직구하는 사람은 이미 매일 그 페이지를 연다. 서비스를 켤 이유를 만들 필요가 없다.
  • 라벨이 공짜고 세 모델이 서로 다르다. 매칭(분류), 세율(분류), 하락(시계열). 포폴에서 겹치지 않는다.
  • 빈틈이 선명하다. AliPrice는 알리 가격 이력만, 쿠팡 쇼핑 도우미는 5천 명에 고장 리뷰, 네이버 가격추적기는 국내만(조사원 확인). "한국 사용자의 최종가 + 직구 간 + 국내 비교"는 못 찾았다(미확인).
  • 슬라이스가 진짜 독립적이다. 추출·규칙·시계열·매칭·알림·운영. 데이터 소스와 모델이 다 다르다.
  • 확장이 자연스럽다. 큐텐·아이허브·일본 아마존을 어댑터로 추가하면 된다.

7. 솔직한 위험과 대응

위험왜 위험한가대응
"최종가"가 틀림통관에서 세금이 더 나오면 신뢰가 끝난다."예상가"로 부르고 항목·세율·환율 출처를 항상 펼쳐 보인다. 세율 분류 확신이 낮으면 범위(₩34,120~36,900)로 보여 준다. 실제 청구액이 달랐다는 신고 탭을 두고 그걸로 규칙·분류기를 고친다.
사이트 약관알리·테무·쿠팡은 자동 수집을 금지한다.서버 크롤링은 하지 않는다. 사용자가 직접 연 페이지를 사용자 동의하에 확장이 읽는 구조로 한정하고, 착수 전에 약관 원문과 법률 자문을 확인한다. 국내 가격은 공식 API만.
DOM 변경으로 깨짐기존 확장이 실제로 그렇게 죽었다(쿠팡 쇼핑 도우미 고장 리뷰).슬라이스 A의 스냅샷 회귀 테스트와 F의 깨짐 알림. 깨진 사이트는 배지를 숨기고 "점검 중"을 띄운다.
동일품 매칭 오탐다른 물건을 같은 물건이라 하면 비교가 거짓이 된다.확신도 높을 때만 "같은 상품", 아니면 "유사 상품"으로 표시. 교정 탭이 라벨이 되어 매주 좋아진다.
면세 규칙 변경정부 TF가 150달러 하향을 검토 중이다[1].규칙은 버전으로 관리하고 F가 관세청 공지를 감시한다. 바뀌면 그날 반영되고 ⑧처럼 사용자에게 알린다.
초기 가격 이력 부족사용자가 적으면 "90일 위치"가 비어 보인다.초기엔 "관측 N건"을 정직하게 표시하고, 최종가 계산과 비교는 이력 없이도 돌아간다.

8. 결정 전에 하루 만에 해 볼 수 있는 것

코드 없이 검증한다. 동기 10명의 최근 직구 주문(알리·테무·아마존)을 받아 상품가·배송비·세금·카드 수수료를 손으로 더해 "실제 낸 돈"과 비교하고, 같은 물건의 쿠팡·네이버 최저가를 찾아 표로 만든다. "원화 결제로 손해 본 사람"과 "국내가 더 쌌던 건"의 비율이 나오면 그게 첫 슬라이드다. 셋 중 하나라도 30%를 넘으면 수요는 충분하다(기준은 제안).

9. 근거

  1. 소액면세 기준 150달러(미국발 200달러), 정부 TF가 하향 검토: SBS Biz
  2. 원화 결제(DCC) 시 3~8% 추가 비용, 이중 환전 구조: beancount.io (2026-07)
  3. 알리가 쿠팡보다 비싼 품목 사례: 이코노미스트 (2025-02)
  4. 알리 MAU 약 900만·테무 약 848만(와이즈앱 2025, 조사원 확인). AliPrice 확장(알리 가격 이력, 사용자 수 미확인), 쿠팡 쇼핑 도우미 약 5천 명·고장 리뷰(조사원 확인).
  5. 네이버 쇼핑 검색 API: 공식, 일 25,000건(조사원 확인). 쿠팡 파트너스 API의 가격 필드는 미확인.

데모와 플로우의 가격·세율·환율·수수료는 예시다. 관세율은 품목마다 다르며 실제 서비스는 관세청 품목분류와 고시환율을 쓴다. 약관 적용 범위는 법률 확인 전까지 미확인.

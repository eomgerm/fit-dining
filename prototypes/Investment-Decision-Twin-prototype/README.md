# SSAFY concept prototypes

하나의 Vite 앱에서 두 개의 자율 프로젝트 후보를 비교할 수 있는 인터랙티브 프로토타입입니다. 우측 하단 전환 버튼으로 오갈 수 있습니다.

## 01. Thesis — Investment Agent Browser

사용자의 자연어 투자 목표를 조사 작업으로 분해하고, 기업 탐색부터 비교, 투자 가설, Decision Gate, 모의 주문까지 연결하는 인터랙티브 웹 프로토타입입니다.

## Core flow

1. 자연어로 투자 조사 목표 입력
2. 에이전트 조사 과정과 근거 스트리밍
3. 후보 기업 선택 및 동적 비교
   - 국내 10개·해외 10개 실제 상장 기업 유니버스
   - P/E, Forward P/E, 부채비율, 현금흐름, 변동성 등 비교 지표 직접 선택
4. 투자 가설과 무효화 조건 작성
5. 기존 행동과 충돌하는 결정을 Decision Gate에서 확인
6. 모의 주문 이후 Decision Twin 업데이트
7. 이후 실적·공시가 사용자가 정한 조건을 실제로 충족하면 가설 재검토 알림

Decision Twin은 별도 결과 화면이 아니라 전체 흐름의 개인화 계층입니다. 과거의 투자 결정, 후보 제외, 비교 기준 수정과 예외 선택을 바탕으로 판단 성향을 구성하고 후보 순위, 기본 비교 지표, Decision Gate와 사후 가설 모니터링에 반영합니다.

기본 주소: `http://127.0.0.1:5174/#/thesis`

## 02. TaxTrace — 국민 영수증

사용자가 입력한 2024년 소득세 결정세액을 중앙정부의 실제 분야별 집행 비중으로 배분한 뒤, 사회복지 → 주택 → 청년월세 한시 특별지원 사업까지 추적합니다.

- 세액은 총급여로 추정하지 않고 사용자가 결정세액을 직접 입력
- 분야별 금액은 열린재정 `OPFI117`의 2024년 실제 집행 비중을 적용한 `비례 귀속 추정`
- 청년월세 사업은 열린재정 `VW_OPFI379`과 국회예산정책처 결산의 실제 예산·집행액 사용
- 약속 일치, 예산 반영, 집행, 결과를 하나의 종합 점수로 합치지 않음
- 중앙정부 집행과 지자체의 최종 수혜자 지급을 구분하고, 미공개 데이터는 `확인 불가`로 표시
- 내려받은 API 원본과 공식 PDF는 `data/taxtrace/`에 보존

주소: `http://127.0.0.1:5174/#/taxtrace`

## Run

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`로 확인합니다.

테스트는 `npm test`로 실행합니다.

## Prototype boundaries

현재 버전은 제품 가설과 핵심 사용자 흐름을 검증하는 결정론적 프론트엔드 프로토타입입니다. 기업·뉴스·공시·재정 수치와 에이전트 실행은 시연용으로 고정되어 있습니다. 실제 투자 추천·실거래·세무 계산·정부 평가·외부 API 호출은 수행하지 않습니다.
